# 🚀 Kyogo Hub & Data Center

Central repository for dynamic data and JSON configurations exclusively utilized by the internal applications of the **Kyogo Development Team**.

> [!WARNING]  
> **INTERNAL USE ONLY**  
> The data endpoints and configurations hosted in this repository are strictly tailored for the Kyogo Development Team ecosystem. External use, scraping, or hotlinking these files in third-party applications is highly discouraged, unsupported, and subject to breaking changes without notice.

## 📂 Data Directory

All internal configuration files are managed inside the `data/` folder:

1. **`api-routes.json`**
   * **Description**: Centralized routing map containing direct API endpoints used across various team projects.

2. **`cfx-servers.json`**
   * **Description**: Database registry and server configuration mappings for Cfx services.

3. **`versions.json`**
   * **Description**: Centralized version control registry for all applications built by Kyogo Development Team.
